# An update about our Code of Conduct and policies
We have refreshed and updated our Code of Conduct which also includes how to report incidents and how it will be enforced if incidents arises.

A new addition is recording policy at our events, which comes into immediate affect especially with smart glasses like Meta/Rayban glasses and discrete recording devices. 

As more conferences like <a href="https://defcon.org/html/links/dc-photo-policy.html">DefCon</a>, <a href="https://www.bbc.com/news/articles/c204le0nvn3o">Monopoly events</a> who run ComicCons in Uk, <a href="https://dublincomiccon.com/faqs/">DublinComicCon</a> updated their policies regarding smart glasses, specifically Meta Glasses, Coding Grace have decided to bring in a policy about a ban in smart glasses at our events.

You can find out updated Code of Conduct (based on EuroPython Society's Code of Conduct) here: <a href="http://localhost:8080/codeofconduct/">https://codinggrace.com/codeofconduct/</a>

Other associated procedures and policies can be found here:

- <a href="https://codinggrace.com/coc/coc-incident-reporting/">Procedure For Reporting Code of Conduct Incidents</a>
- <a href="https://codinggrace.com/coc/coc-enforcement-procedure/">Procedures for Incident Response</a>
- <a href="https://codinggrace.com/coc/recording-policy/">Recording Policy</a>

You can also find our latest Code of Conduct, procedures and policies via <a href="https://codeberg.org/codinggrace/code-of-conduct">https://codeberg.org/codinggrace/code-of-conduct</a>.

If you have any questions, you can email <a href="mailto:contact@codinggrace.com">contact@codinggrace.com</a>.
