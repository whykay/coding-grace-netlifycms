## ⚡️ Welcome to the world of electronics with Python that can interact with electronics (it's called CircuitPython). 

This one-day hands-on workshop will demonstrate problem solving and thinking skills that will help teachers support their students in building and making software and electronics projects using their own ideas and imagination. The workshop will give a taste of Python programming language which includes CircuitPython which is used to interact with electronics, and show how to read, write, test and modify hardware and software programs.

The workshop will introduce participants to circuits which includes breadboards, electronic components, and how they all work together. It also covers what is a Pico microcontroller, and how to write Python code for the Pico to work with electronics; this develops an understanding of how they interrelate, and how creativity and technology works together.

By the end of the session, participants will be able to programme a game controller connected to a Pico, and when connected to a laptop, turns it into an input device that can be used to play games. As it's customisable, participants can change and modify it how it behaves as it's written in Python.

NOTE: There's only **20 places** for this workshop. If there's enough interest, we will host another series in the near future.

Vicky Twomey-Lee and Michael Twomey will be the workshop facilitators. Both are co-founders of Coding Grace, and no strangers to running workshops and community events over the past decade.

## **What we will be covering:**
- Intro to Circuits
- A Taste of Electronics
- A Taste of Pico
- More with CircuitPython and Pico
- ALT.CTRL GamePad
